About ParkSmart

ParkSmart is a web-based Smart Parking Allocation System developed to simplify and improve parking management. It provides a digital platform for checking parking slot availability, registering vehicles, and managing parking booking requests. The system manages a permanent inventory of 20 parking slots across three zones. It uses database connectivity, data structures, algorithms, and machine learning concepts to make parking management more organized and efficient.

Our Purpose

The main purpose of ParkSmart is to reduce the time and effort required to manage parking spaces manually. It helps users view parking availability and allows administrators to process booking requests systematically.

How the System Works

  • Users enter their personal and vehicle details.
  • Booking requests are stored in a FIFO queue.
  • The system selects the nearest available slot using a Greedy strategy.
  • MySQL stores user, vehicle, slot, and booking information.
  • AI-based functionality estimates future parking availability.
  • Analytics display parking usage and booking trends.

Technology Stack

  • HTML, CSS and JavaScript
  • Java Servlets and JDBC
  • MySQL Database
  • Python and Flask
  • Pandas, NumPy and Matplotlib
  • Scikit-learn
  • Apache NetBeans and Apache Tomcat

Project Goal

ParkSmart demonstrates how web development, database management, algorithm design, and machine learning can work together to solve a practical real-world parking management problem.
